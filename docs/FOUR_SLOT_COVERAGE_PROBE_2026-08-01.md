# Frozen Four-Slot Coverage Probe

## Question

The frozen unified-selector experiment proves that the current independent
scalar score does not close the gap between the 32-candidate pool and the
selected Top-4. It does **not** prove that a four-slot selector fixes it.

This experiment directly tests the narrower hypothesis:

> Can the same frozen candidate descriptors support four jointly selected,
> non-repeated lanes with materially higher GT coverage than scalar Top-4?

No detector, FPN, decoder, geometry head, or candidate curve is trained.

## Arms

1. `source raw Top-4`: the deployed unified scalar selector without NMS.
2. `source NMS Top-4`: diagnostic geometry suppression control.
3. `MMR Top-4`: source scores with a train-selected curve-redundancy penalty.
4. `four-slot pointer`: four image-conditioned slots cross-attend to all
   candidate descriptors and are decoded without replacement. Slots predicted
   as present are assigned first; unused Top-4 positions are filled by the
   source score so inactive slots cannot steal a real lane candidate.
5. `oracle Top-4`: upper bound from official raster IoU; never deployable.

The pointer receives left-to-right canonical GT slots. Each slot target is a
soft distribution over all candidates near that GT's best IoU, so duplicate
candidates are not arbitrarily forced into contradictory positive/negative
labels. A pairwise shared-GT affinity term discourages different slots from
covering the same physical lane.

MMR parameters are selected only on the frozen training cache. Pointer model
selection uses the frozen validation cache, matching the previous diagnostic
protocol. The reported numbers are diagnostic recall, not official benchmark
F1.

## Gate

Relative to source raw Top-4 on the same 256 validation images, either learned
four-slot selection or MMR must gain:

- at least `+5.0` recall points at IoU 0.50; and
- at least `+3.0` recall points at IoU 0.70.

Interpretation:

- pointer passes: learned explicit coverage is supported; a full joint model
  is justified;
- only MMR passes: geometric diversity is useful, but this pointer design is
  not yet justified;
- both fail: do not spend a full training run on the four-slot hypothesis.

## Command

The command reuses caches generated by
`diagnose_culane_dla34_unified_selector_frozen_10k.sh`:

```bash
bash scripts/probe_culane_dla34_four_slot_coverage_frozen.sh
```

The result is written to:

```text
outputs/diagnostics/dla34_four_slot_coverage_frozen_10k/
  four_slot_coverage_probe.json
```
